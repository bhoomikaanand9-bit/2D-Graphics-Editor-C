# 2D Graphics Editor in C

## Description

This project is a menu-driven 2D Graphics Editor implemented using C programming language and a 2D character array.

The canvas is initialized with `_` characters and graphical objects are drawn using `*`.

## Features

* Draw Rectangle
* Draw Line
* Draw Triangle
* Draw Circle
* Delete Objects
* Modify Objects
* Display Canvas
* Clear Canvas

## Concepts Used

* Arrays
* Functions
* Loops
* Conditional Statements
* 2D Character Array

## Compliation
gcc graphics_editor.c -o graphics_editor -lm
./graphics_editor
